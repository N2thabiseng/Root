# Mel Wear Website

## Project Overview

Mel Wear is a clothing brand website created to showcase the brand, its products, and services online.

The website allows customers to learn more about Mel Wear, view products and images, find contact information, and submit enquiries.

The website was developed using HTML and Visual Studio Code.

## Purpose of the Website

The purpose of the Mel Wear website is to create an online presence for the brand and provide customers with an easy way to learn about the business, view its products, explore the gallery, and make enquiries.

The website aims to:

- Promote the Mel Wear clothing brand online.
- Showcase Mel Wear products.
- Provide customers with product information and prices.
- Display images of Mel Wear products.
- Provide business contact information.
- Allow customers to submit enquiries.
- Provide an easy-to-use navigation system.
